## Manuscript: Data and Code Availability

The IMPACT system source, automatic expert-matching implementation and weights,
public expert reference database, apparatus/stimuli specification, and
dependency-installation instructions are available at
**https://github.com/dailyminiii/IMPACT**,
archived as version 1.0.0 at **[ZENODO-DOI]**. The intervention-study records
(motion, EMG, landing, questionnaires, interview, and participant-level
derivatives), user-study analysis workspace, and qualitative materials are not
publicly available because the approved consent and IRB protocol do not permit
their redistribution. The public expert reference database is distinct from
the N=12 intervention-study records and documents its source and processing in
the repository.

## Response to the handling editor: availability item

We have deposited the IMPACT implementation in a citable public repository
(https://github.com/dailyminiii/IMPACT; Zenodo archive [ZENODO-DOI]). The release includes the
first-party Unity implementation, AutoEncoder-based expert matching code and
weights, five-expert public reference/matching data, the apparatus and stimuli
specification, and reproducible installation instructions for external Unity
dependencies. To make the system inspectable and reusable without
redistributing licensed Unity assets, the repository excludes raw third-party
avatars, anatomy/court/racket assets, the chart package, and the device SDK;
the exact official acquisition/install paths are documented.

We cannot deposit the N=12 intervention-study records, participant-level
derivatives, qualitative materials/codebook, or the original user-study
analysis workspace. The approved consent and IRB protocol do not allow their
public redistribution. We have revised the manuscript's availability statement
to make this limitation explicit and distinguish the released public expert
reference data from the restricted intervention-study data.
